# 播放器与房间使用说明

## 继续上次观看

永久房间在最后一人离开后暂停，保存当前视频、播放位置和待播列表。再次进入时恢复，
需要开始观看时再播放。公开的永久房间在无人在线时仍出现在房间列表；未公开列出的房间
继续通过原房间路径访问。

此功能不保存所有已经播放完的链接，也不会恢复被主动移出队列的内容。希望以后重看整个列表时，
请另外导出或保存播放列表。临时房间仍遵循临时生命周期。

## 点击、聊天和全屏

-   点击视频画面显示或收起控件；播放时无操作约 3 秒后自动收起。暂停、播放错误、拖动进度条、打开菜单或聊天时保留控件，方便继续操作。
-   手机上点击画面不会直接切换播放/暂停。桌面双击画面切换全屏，单击收起控件会有短暂等待，以区分双击。
-   点击聊天按钮仅打开聊天面板；需要发消息时再点击输入框，不会自动弹出手机键盘。收起聊天时保留尚未发送的草稿。
-   聊天面板打开时点击画面会收起聊天及控件；暂停状态下仍保留播放控件。
-   全屏按钮只让播放器及其控件占满屏幕，锁定背景页面滚动；退出后恢复原页面位置。浏览器无法使用原生全屏时会切换到网页内全屏。

影院模式只调整页面布局，仍可滚动查看视频下方内容，与全屏分开使用。

## 长按倍速和左右滑动

播放时在画面上长按约 500 毫秒，以 **2 倍速同步播放整个房间**；松手恢复长按前的速度。
此操作需要调整房间倍速的权限，暂停或直播时不启用。一个人的长按不会抢占另一个人的长按。
播放暂停、切换视频、离开房间或连接中断时会结束临时倍速；网络异常时服务端会在失去续期后
最多约 5 秒自动恢复。如果其他人明确选择了新的倍速，以新的选择为准。

手机上向右滑动前进、向左滑动后退，默认每次 10 秒。可在播放器设置中选择 5、10 或 30 秒。
滑动过程中显示预览，松手时才提交一次进度改变并同步全房间；取消手势不会跳转。
此操作需要调整房间播放进度的权限，不能超过媒体已知的播放范围。竖向滑动、多指操作和
系统边缘手势不会触发跳转；长按倍速与滑动跳转不会在同一次手势中同时执行。

## 键盘快捷键

可在播放器设置或按 `?` 打开快捷键说明。输入框、中文输入法组合输入、菜单、对话框、
按钮及滑块获得焦点时，不抢占它们的键盘操作；浏览器组合快捷键也保留。

| 按键          | 操作                                                  |
| ------------- | ----------------------------------------------------- |
| `Space` / `K` | 播放或暂停                                            |
| `←` / `→`     | 后退或前进 5 秒                                       |
| `J` / `L`     | 后退或前进 10 秒                                      |
| `↑` / `↓`     | 本机音量增加或减少 5%                                 |
| `M`           | 本机静音或取消静音                                    |
| `F`           | 切换播放器全屏                                        |
| `Esc`         | 关闭面板/菜单，或退出全屏；原生全屏优先遵循浏览器行为 |
| `T`           | 显示或收起聊天，不自动聚焦输入框                      |
| `Home`        | 回到视频开头                                          |
| `End`         | 跳过当前视频，需要房间的跳过权限                      |
| `?`           | 打开操作说明                                          |

播放、跳转和跳过仍受房间权限限制；音量、静音、全屏及控件显示只影响自己的设备。

## 当前集数与改名

显示控件时，画面上方会显示当前标题。标题缺失时显示文件名，不把链接签名参数当作标题。
可以识别 `第03集`、`第十二集`、`S02E03`、`EP003` 或单独编号的 `03.mp4` 等明确格式；
没有可靠集数信息时只显示标题，不把年份、分辨率或随机数字猜成集数。

用户列表旁的“改名”按钮用于修改你的用户名或访客昵称，按钮说明会明确提示这一用途。
它不会修改房间名称或视频标题。

同一部剧的链接只有数字变化时，可考虑将来增加“识别编号 → 指定范围 → 少量并发检查 →
预览确认 → 批量入队”的功能。本版没有自动探测或批量添加下一集，集数显示只根据当前视频信息识别。

## 语言和管理权限

首次加载 cn3 会把旧语言设置迁移为简体中文，之后仍可自行切换语言。已打开的 cn2 或更早页面
需要先刷新或重新打开一次；从 cn3 起会检查新版本并自动刷新，正在输入时延后处理。

房间没有通用的默认管理员账号；
永久房间的房主及其分配的房间管理员负责各自房间的管理。服务器运维密钥与网页登录密码分开。
