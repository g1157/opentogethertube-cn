# 播放器与房间使用说明

## 继续上次观看

房间在最后一人离开后暂停。离开前正在播放的 MP4、HLS 或 DASH 点播视频，首位有播放权限的观众
重新进入后先加载保存的位置，等本机画面和播放就绪后再启动房间时间，避免黑屏准备期间漏看内容。
原本手动暂停的房间保持暂停；浏览器拦截自动播放时会提示点击播放。已有观众正在观看时，
新加入的人加载并跟上当前进度，其他人的播放继续进行。

永久房保存当前视频、播放位置和待播列表，公开的永久房在无人在线时仍出现在房间列表；
未公开列出的房间继续通过原路径访问。仅从数据库恢复的房间保持暂停，可以手动继续观看。
临时房只适合短期使用：缺省无人约 5 分钟自动回收并清除临时快照，不会长期保存观看记录。
Redis 的 2 小时过期时间是异常情况下的兜底，不代表空房正常保留 2 小时。具体时限以站点配置为准。

此功能不保存所有已经播放完的链接，也不会恢复被主动移出队列的内容。希望以后重看整个列表时，
请另外导出或保存播放列表。

## 点击、聊天和全屏

-   点击视频画面显示或收起控件；播放时默认无操作约 3 秒后自动收起，可改为 2、3、5 或 10 秒。暂停、播放错误、拖动进度条、打开菜单或聊天时保留控件，方便继续操作。
-   手机单击显示或收起控件，双击暂停或继续播放，需要房间播放/暂停权限，并同步给房间其他人。单击会短暂等待以识别双击，滑动和长按不会同时触发双击。
-   桌面双击画面切换全屏。全屏播放时，鼠标静止会随控件一起隐藏，移动鼠标即重新显示；点击全屏按钮后把鼠标停留在按钮上也能自动隐藏。使用键盘操作控件或打开菜单时保持可见。
-   点击聊天按钮仅打开聊天面板；需要发消息时再点击输入框，不会自动弹出手机键盘。收起聊天时保留尚未发送的草稿。
-   电脑端按 Enter（含数字键盘 Enter）打开聊天并自动聚焦，可直接输入；再次 Enter 发送，发送后收起聊天。中文输入法选词时不会误发送，长按 Enter 不会连续触发。Esc 收起并保留草稿。正在操作其他输入框、按钮或弹窗时保留它们原来的按键行为。
-   聊天面板打开时点击画面会收起聊天及控件；暂停状态下仍保留播放控件。
-   全屏按钮只让播放器及其控件占满屏幕，锁定背景页面滚动；退出后恢复原页面位置。浏览器无法使用原生全屏时会切换到网页内全屏。

影院模式只调整页面布局，仍可滚动查看视频下方内容，与全屏分开使用。

## 本机观看偏好

房间上方的个人设置和播放器设置中的观看偏好使用同一组配置，保存到当前浏览器，不改变其他人的设置。

| 设置 | 默认 | 可选值与作用 |
| --- | --- | --- |
| 新消息停留时间 | 5 秒 | 关闭、3、5、10、20 秒；仅影响收起聊天时的浮层，打开聊天仍能查看历史 |
| 新消息提示音 | 关闭 | 可在本机设置或播放器观看偏好中开启、关闭；不改变视频音量 |
| 控件自动隐藏 | 3 秒 | 2、3、5、10 秒；全屏鼠标同时隐藏 |
| HLS 预缓冲 | 60 秒 | 30、60、120 秒；仅 hls.js 生效，实际缓存仍受码率、内存与网络限制 |
| 滑动跳转步长 | 10 秒 | 5、10、30 秒；跳转会同步整个房间，需要权限 |

音量、静音、消息提示音音量、音频增强、主题和影院布局也可调整。首次升级到 cn6 时消息提示音会关闭，之后保留手动选择。字幕和画质取决于当前视频源提供的轨道。
固定 MP4 链接通常只有一份画质，无法仅通过调播放器参数把它变成低码率版本。

## 连接、加载错误与缓冲

离开房间后其他人切换视频，再进入时会先等待本次房间同步，然后加载当前视频；不会先启动上次残留的片源。连接等待期间显示提示。进度条表示房间统一时间，本机是否已经开始播放还要以画面和播放状态为准。

本机还未显示画面时，会区分“正在准备视频”“正在加载房间当前进度”“正在缓冲视频”和
“正在等待画面”，配合等待动画、已等待秒数及可用的连续缓冲秒数。准备阶段不显示虚构的下载百分比或倒计时；
等待多久取决于片源、网络和解码情况。超过约 15 秒会提示加载较慢，并为支持重载的播放器提供
“仅重载我的视频”。准备上次进度失败时也可重试，不必反复换集。浏览器阻止自动播放和最终加载错误
有各自的提示，不会一直显示相同的等待动画。

房间的 WebSocket 握手及首次房间同步超过 15 秒会显示超时并重试，重试间隔最多 30 秒。
恢复网络后会立即尝试重连，也可以点击“立即重连”。服务器明确踢出或房间不存在时不会无限重试。

HTTP 入口使用明文 `ws://`。部分 HTTP 系统代理不能正确转发 WebSocket 升级请求：普通网页可打开，
房间仍可能连接失败。可将本站主机地址加入**系统代理绕过列表**，或使用支持 WebSocket 的代理；
仅增加代理内的“路由直连”规则，浏览器仍可能经过 HTTP 代理。管理员配置受信任的 HTTPS 入口后，
房间会自动使用 `wss://`；服务器反向代理也必须支持 WebSocket。

MP4/HLS 遇到短暂网络错误会进行有限次数的恢复；失败后显示错误原因，可点击“重新加载本机视频”。
它不会向房间发送暂停或跳转操作，也不会重新添加队列。无效链接、拒绝跨域访问、权限过期或浏览器不支持
的格式仍可能需要更换链接或视频源。恢复过程中会保留观看进度并遵循最新的房间播放/暂停状态。

缓冲期间会减少自动追赶进度的频率，避免不断中断同一段下载；房间中明确的跳转操作仍及时同步。
如果持续下载速度低于视频码率，任何缓存参数都无法保证连续播放。MP4 的缓存由浏览器控制，可以先暂停
等待预加载、选择更稳定的线路，或使用较低码率的视频源。HLS 有多档画质时优先使用自动画质，较大预缓冲
适合有短暂网络抖动且内存充足的设备。

## 长按倍速和左右滑动

播放时在画面上长按约 500 毫秒，以 **2 倍速同步播放整个房间**；松手恢复长按前的速度。
此操作需要调整房间倍速的权限，暂停或直播时不启用。一个人的长按不会抢占另一个人的长按。
播放暂停、切换视频、离开房间或连接中断时会结束临时倍速；网络异常时服务端会在失去续期后
最多约 5 秒自动恢复。如果其他人明确选择了新的倍速，以新的选择为准。

手机上向右滑动前进、向左滑动后退，默认每次 10 秒。可在播放器设置中选择 5、10 或 30 秒。
滑动过程中显示预览，松手时才提交一次进度改变并同步全房间；取消手势不会跳转。
此操作需要调整房间播放进度的权限，不能超过媒体已知的播放范围。竖向滑动、多指操作和
系统边缘手势不会触发跳转；长按倍速与滑动跳转不会在同一次手势中同时执行。

## 键盘快捷键

可在播放器设置或按 `?` 打开快捷键说明。输入框、中文输入法组合输入、菜单、对话框、
按钮及滑块获得焦点时，不抢占它们的键盘操作；浏览器组合快捷键也保留。

| 按键          | 操作                                                  |
| ------------- | ----------------------------------------------------- |
| `Space` / `K` | 播放或暂停                                            |
| `←` / `→`     | 后退或前进 5 秒                                       |
| `J` / `L`     | 后退或前进 10 秒                                      |
| `↑` / `↓`     | 本机音量增加或减少 5%                                 |
| `M`           | 本机静音或取消静音                                    |
| `F`           | 切换播放器全屏                                        |
| `Esc`         | 关闭面板/菜单，或退出全屏；原生全屏优先遵循浏览器行为 |
| `T`           | 显示或收起聊天，不自动聚焦输入框                      |
| `Home`        | 回到视频开头                                          |
| `End`         | 跳过当前视频，需要房间的跳过权限                      |
| `?`           | 打开操作说明                                          |

播放、跳转和跳过仍受房间权限限制；音量、静音、全屏及控件显示只影响自己的设备。

## 当前集数与改名

显示控件时，画面上方会显示当前标题。标题缺失时显示文件名，不把链接签名参数当作标题。
可以识别 `第03集`、`第十二集`、`S02E03`、`EP003` 或单独编号的 `03.mp4` 等明确格式；
没有可靠集数信息时只显示标题，不把年份、分辨率或随机数字猜成集数。

用户列表旁的“改名”按钮用于修改你的用户名或访客昵称，按钮说明会明确提示这一用途。
它不会修改房间名称或视频标题。

同一部剧的链接只有数字变化时，可考虑将来增加“识别编号 → 指定范围 → 少量并发检查 →
预览确认 → 批量入队”的功能。本版没有自动探测或批量添加下一集，集数显示只根据当前视频信息识别。

## 语言和管理权限

首次加载 cn3 会把旧语言设置迁移为简体中文，之后仍可自行切换语言。已打开的 cn2 或更早页面
需要先刷新或重新打开一次；从 cn3 起会检查新版本并自动刷新，正在输入时延后处理。

房间没有通用的默认管理员账号；
永久房间的房主及其分配的房间管理员负责各自房间的管理。服务器运维密钥与网页登录密码分开。
