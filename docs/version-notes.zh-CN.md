# 版本记录（简体中文分支）

各版本的改动与数据库迁移情况。发布提交对应 Git 标签 `v0.15.0-cn2` 起；更早的历史见
`archive/history` 分支与 `v0.14.1` 标签。`v1.0.0` 起跳出 cn 序列，作为本分支的正式大版本，
标签与镜像名不再带 cn 编号。

-   **v1.0.0**：画质增强重做，新增播放详情与同剧集探测。无数据库迁移、无新增依赖。
    **画质增强**：自动倍率不再低于源分辨率（手机上 1080p 此前会渲染 0.4× 的画布，锐化反而
    把画面做得比原画更软），并以 4K 像素预算兜底超大源；清晰化档的放大换成 EASU（移植自
    AMD FidelityFX FSR 1.0，MIT，许可证随源码保留），放大时按「EASU → 锐化」两遍渲染，
    画布不大于源分辨率时仍是单遍，默认锐化强度从 0.75 提到 0.9；渲染倍率新增 2.5× 与 3×
    （上限从 2× 提到 3×）；AI 超分新增「质量」档（官方 A+A 预设
    `Restore → Upscale → Restore → Upscale`，感知质量最高，GPU 开销约为快速档两倍），
    自动降档顺序改为 质量 → 快速 → 清晰化 → 降倍率 → 关闭。设置菜单内新增可展开的
    「画质增强说明」。本地真实 GPU 上以 720p → 2K 对比真值（PSNR）：细节区 浏览器缩放
    24.81 dB / 旧管线 21.65 dB / 新管线 26.23 dB；AI 超分两档在真实 WebGPU 设备上均验证可出画。
    **WebGPU 失败可见化**：WebGPU 的校验失败、设备丢失与未捕获错误此前是静默的（Firefox
    等实现不完整时会留一块黑画布且不降档），现在会用错误作用域捕获、按档位回退，并把
    原因写进播放详情面板与控制台。
    **播放详情**：设置菜单「视频详情」或画面右键打开，悬浮在画面左上角（不暂停、不遮挡操作，
    仅关闭按钮可点），显示分辨率、进度 / 时长、片源类型与源主机、播放状态、倍速、缓冲前瞻、
    丢帧、实测帧率、与房间偏差、增强模式与渲染目标、上次增强错误、视口 / DPR、WebGPU 设备名等，
    仅在面板打开时采样。
    **添加页**：预览卡片按当前设置与显示尺寸显示「渲染后画质」；解析直链后会在后台静默探测
    相邻集数（递增最后一个、必要时倒数第二个数字，跳过年份与分辨率数字），找到后给出一键
    加入队列的「同剧集」提示，直链（MP4/HLS/DASH）的源分辨率由服务端从 ffprobe / 清单读取。
    **控件条**：暂停 / 音量 / 全屏那一排改为换行布局（此前是横向滚动容器，滚轮或触控板扫过会
    把整排控件横向拖走）。
    旧客户端按既有版本检查自动刷新；已固定 `OTT_IMAGE` 的部署需要改标签后再 `pull`。

    偏好一次性迁移为 `zh-CN`，保留其他本地设置，不删除账号或房间数据。均无新增数据库迁移。

-   **cn7**：本机视频准备、跳转、缓冲及等待画面提示（含已等待时间与连续缓冲秒数），长时间等待可
    仅重载自己的视频，支持时以实际视频帧确认画面就绪；临时房和永久房的空房时钟都暂停，重启后
    仅从 PostgreSQL 恢复的房间也保持暂停。临时房沿用空闲回收，缺省无人约 5 分钟卸载并清除
    Redis 快照，2 小时 Redis TTL 兜底，有人观看时续期。无生产数据库迁移。
-   **cn8**：移除遮挡画面的自动播放提示，改用原有播放按钮启动本机；修复刷新后的播放状态竞态，
    用实际出帧计数补充视频帧回调；跳转时立即暂停本机旧位置，目标位置有数据后恢复。手机竖屏
    精简控件、横屏或全屏展开；用户进出与跳转提醒可设为关闭或 1、2、3、5、10、20 秒，默认 3 秒。
    无服务端协议或数据库迁移。
-   **cn9**：降低原生视频启动要求，当前帧数据可用即可尝试播放；缓冲恢复和本机重载会及时取消
    恢复超时。`FFPROBE_STRATEGY` 默认与部署值改为 `run`，通过 HTTP Range 读取 MP4 尾部索引，
    避免旧 `stream` 顺序下载大文件后超时；添加面板增加 45 秒请求上限、慢响应提示和重试，
    详见 [MP4 解析与排查](media-parsing.zh-CN.md)。无生产数据库迁移；已有环境中显式设置的
    `stream` 需改为 `run`，重建应用容器后才生效。
-   **cn10**：发布与部署流程更新——镜像由 GitHub Actions 构建并发布到
    `ghcr.io/g1157/opentogethertube-cn`，部署改为 `docker compose pull && up -d`（服务器不再编译，
    也不需要 Node.js）；包含 cn9 之后的原生播放探测与队列修复。无数据库迁移。
-   **cn11**：画质增强新增「进阶」设置——锐化强度、渲染倍率、性能不足时自动降档（可关闭），
    主档位仍为 关闭/清晰化/AI 超分。修复手机开启增强后掉帧的根因：渲染目标此前被强制不低于
    原片分辨率（1080p 在手机上仍渲染 1920×1080，约 6 倍无效像素），现按显示尺寸计算并允许
    低于 1×。自动降档由「一跳到底」改为逐级下探，且只降渲染倍率和算法——锐化强度只改一个
    uniform，着色器仍每像素采样 5 次，降它不减轻负载，故保留为纯画质选项。手机首次使用默认
    落在较轻档位，不覆盖用户已显式选择的档位。同时修复三处渲染生命周期缺陷：切档位或换片源
    时复用同一 canvas 会取不到新上下文（一个 canvas 只认第一次取得的上下文类型，WebGL2 与
    WebGPU 互斥，且清晰化停止时会主动释放上下文），现每次启动都新建 canvas；初始化慢于下一
    次启动时会覆盖当前渲染器引用并使其失联泄漏，现改为校验代次后再安装；暂停、拖动和缓冲期间
    不出帧，恢复播放的首帧曾把整段静止时间算进掉帧窗口而误降档，现按帧间空档重新计时。另修复
    「清晰化」档画面上下颠倒，以及 3.4MB 的 anime4k-webgpu 被并入启动 vendor 块、导致每个
    页面（含首页）首开都要下载它的问题——现改为仅在选中 AI 超分时按需加载。无数据库迁移。
-   **cn12**：Direct / HLS / DASH 新增本机速率微调：300 ms 起调、150 ms 停止、幅度不超过房间
    速度的 ±8%，最多持续 8 秒，未收敛回退为硬跳；观察不再被硬跳节流挡住。暂停、准备握手、
    换源、拖动、恢复与临时 2× 期间取消微调，房间倍速变化后重新叠加；倍速菜单仍显示房间速度。
    **YouTube、PeerTube、Vimeo 不支持该微调**，继续沿用原有纠偏。参数是待真机标定的工程
    起点，测量方法与未完成项见 [同步与测量记录](playback-sync.zh-CN.md)。无数据库迁移。

    设置默认 `off`；现有房间不会自动开启。Cloudflare 预览暂不提供此服务端功能。

-   **cn14**：修复 2026-09-13 用户体验审查中的全部问题，详见
    [用户体验与产品审查](ux-review-2026-09-13.zh-CN.md)。要点：
    **服务端**——请求失败不再把发起者踢出房间（新增 `ServerMessageError` 消息与

    其他人不再被强制对齐而短暂卡顿；本机重新对齐增加 300 ms 漂移门槛与寻址原因日志。
    **播放**——没有 CORS 的直链自动去掉 `crossorigin` 重试并关闭画质增强（有提示），
    错误文案不再断言“格式不支持”；新增“房间正在播放 → 点击加入播放”遮罩，控制栏在
    本机未播时执行本机解锁而不是暂停全房间；缓冲时一起暂停与准备握手不受影响。
    **界面与文案**——房间事件提示全部中文化；导航“常见问题”改为站内帮助页 `/help`
    （保留上游文档外链）；永久房表单打开不再直接报“名称为必填项”；被踢提示可读并带
    “重新连接”，关闭码 4000 先有限重连；直链 `Full Link:` 描述本地化；服务端错误统一
    中文映射（不泄漏英文原文，原始信息留在控制台）；添加等待可取消；新版本改为提示条而
    非静默刷新；聊天空态；房间列表与房间首屏骨架屏；401 自动刷新令牌并提示重新登录；
    房间可见性兜底文案；SponsorBlock 分类与偏好设置选项本地化；邀请链接点击全选。
    无生产数据库迁移；Cloudflare 预览版不含其中依赖服务端的功能。

-   **cn21**：直链播放失败的提示改为按证据说话，便签面板可折叠。
    **失败诊断**：`MediaError.code=4` 同时覆盖「源站不可达（被墙、DNS 异常、代理分流走错）」
    与「格式/防盗链放不了」，过去一律提示「未允许跨域访问（CORS）」会误导。现在失败时做一次
    `no-cors` 的可达性探测（任意 HTTP 响应即视为可达），分别提示「你这台设备连不上视频源」或
    「能连上但浏览器无法播放」；只有确认去掉 `crossorigin` 后确实能播，才提示已关闭画质增强。
    连接提示文案补充直连场景：本站经 Cloudflare 对外，部分网络到该线路的 WebSocket 会被限速或
    阻断，直连用户可换网络重试，代理用户检查绕过列表；帮助页同步新增该条。
    **便签折叠**：桌面端便签面板新增头部与折叠按钮，收起后视频恢复居中（不再占用右侧列宽），
    折叠状态记在本机设置里；窄屏仍用标签页。无数据库迁移。
    **运维配置（不影响镜像）**：为国内网络加了不经 Cloudflare 的裸 IP 直连入口——8082 明文
    （看视频够用，首页约 50 ms，对比经 Cloudflare 边缘 3 s 以上）、443/8443 走 Caddy + 自签名
    证书（语音需要安全上下文，浏览器首次会提示证书不受信任）。实测腾讯云只按 Host 头拦明文 HTTP
    （任意端口带域名都会 302 到 webblock 页），裸 IP 与 HTTPS 都不拦。详见
    [部署文档](../DEPLOYMENT.md#可选裸-ip-直连入口国内网络不稳时的备用通道)。
