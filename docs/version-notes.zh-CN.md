# 版本记录（简体中文分支）

各版本的改动与数据库迁移情况。发布提交对应 Git 标签 `v0.15.0-cn2` 起；更早的历史见
`archive/history` 分支与 `v0.14.1` 标签。

- **cn1–cn3**：中文化界面、可靠永久房与同步播放手势。从 cn3 起，首次加载会把本地保存的旧语言
  偏好一次性迁移为 `zh-CN`，保留其他本地设置，不删除账号或房间数据。均无新增数据库迁移。
- **cn4**：选择性移植官方 master 提交 `4ea9029429a98561ba7c213c54c55ef0f0c56800` 的配色、字体、
  首页、导航与房间卡片，兼容保留 cn1–cn3 的功能；核心仍以 v0.15.0 为基线，没有整体切换到
  开发分支。无数据库迁移。
- **cn5**：消息与控件隐藏时长设置、全屏鼠标隐藏、手机双击播放/暂停、连接超时重试；为 MP4/HLS
  增加有限的错误恢复和本机重新加载。无数据库迁移；HLS 预缓冲设置仅适用于 hls.js，MP4 和
  浏览器原生 HLS 仍由浏览器管理缓存。
- **cn6**：Enter 打开聊天并自动聚焦、再次 Enter 发送；新消息提示音默认关闭，可在本机设置或
  播放器观看偏好中开启（首次应用新默认值，之后保留用户选择）；修复离房重进先加载旧片源、
  身份缓存重复等待、旧页面误清理新页面消息监听；首次房间同步完成后才启动当前视频。无数据库迁移。
- **cn7**：本机视频准备、跳转、缓冲及等待画面提示（含已等待时间与连续缓冲秒数），长时间等待可
  仅重载自己的视频，支持时以实际视频帧确认画面就绪；临时房和永久房的空房时钟都暂停，重启后
  仅从 PostgreSQL 恢复的房间也保持暂停。临时房沿用空闲回收，缺省无人约 5 分钟卸载并清除
  Redis 快照，2 小时 Redis TTL 兜底，有人观看时续期。无生产数据库迁移。
- **cn8**：移除遮挡画面的自动播放提示，改用原有播放按钮启动本机；修复刷新后的播放状态竞态，
  用实际出帧计数补充视频帧回调；跳转时立即暂停本机旧位置，目标位置有数据后恢复。手机竖屏
  精简控件、横屏或全屏展开；用户进出与跳转提醒可设为关闭或 1、2、3、5、10、20 秒，默认 3 秒。
  无服务端协议或数据库迁移。
- **cn9**：降低原生视频启动要求，当前帧数据可用即可尝试播放；缓冲恢复和本机重载会及时取消
  恢复超时。`FFPROBE_STRATEGY` 默认与部署值改为 `run`，通过 HTTP Range 读取 MP4 尾部索引，
  避免旧 `stream` 顺序下载大文件后超时；添加面板增加 45 秒请求上限、慢响应提示和重试，
  详见 [MP4 解析与排查](media-parsing.zh-CN.md)。无生产数据库迁移；已有环境中显式设置的
  `stream` 需改为 `run`，重建应用容器后才生效。
