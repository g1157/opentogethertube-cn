# 播放详情（视频数据面板）

播放器右上角设置（齿轮）→“视频详情”打开一个悬浮面板，列出当前视频与播放环境的实时数据；
在画面上点右键也能直接打开同一面板（快捷键说明里也列了这一条）。面板悬浮在画面左上角，
只占一角、不暂停播放；除右上角的关闭按钮外整体不接收点击，画面上的手势与控件照常可用。
面板每秒刷新一次。

## 显示内容

| 分组 | 字段 |
| --- | --- |
| 视频 | 分辨率、进度 / 时长、片源类型、源主机 |
| 播放 | 状态、播放倍速、已缓冲前瞻、丢帧、实测帧率、与房间偏差 |
| 画质增强 | 增强模式、渲染目标（含实际倍率）、自动降档、增强渲染中的实际尺寸、上次增强错误 |
| 设备与环境 | 视口 / DPR、WebGPU 与设备名、增强倍率上限 |

数值来源都是本机可查的事实，没有估算：

-   **实测帧率**在 1 秒窗口内用 `requestVideoFrameCallback` 计数；暂停或后台标签页不产生
    帧回调，此时显示“—”。
-   **丢帧**来自 `getVideoPlaybackQuality()`（浏览器不支持时显示“—”）。
-   **与房间偏差**是“按房间状态推算的位置”减去本机 `currentTime`；房间未在播放时不计算。
-   **渲染目标**用与画质增强相同的尺寸计算（显示框 × DPR，自动档不低于源分辨率、上限 3×），
    因此它显示的就是增强层实际渲染的像素数。

## 成本与隐私

面板关闭时不采样：打开才开始每秒一次的读取，关闭立刻停止。所有数值都在本机计算，不上报。

## 限制

-   嵌入播放器（YouTube、Vimeo 等 iframe）没有可读的 `video` 元素，多数字段显示“—”，
    状态显示“嵌入播放器”。
-   浏览器的跨域与播放器实现差异会影响个别字段（例如部分 HLS 实现不提供丢帧统计）。
-   面板只做展示，不修改播放状态，也不触发重载。

## 验证范围

单元测试覆盖字段采集与格式化（分辨率、缓冲前瞻、丢帧、偏差符号、时间格式、缺失元素时的
空值），组件测试覆盖面板渲染与“嵌入播放器”空态；设置菜单入口与右键入口在组件层接线，
未做真机长时间观察与多浏览器逐项核对。
